# Project working instructions

## Clean up after each task

- Before finishing, remove temporary previews, screenshots, contact sheets, browser profiles, scratch scripts, and other artifacts created solely to implement or verify the task, including files ignored by Git.
- Keep production assets and intentional documentation deliverables. Do not leave temporary previews behind simply because they are ignored by Git or excluded from publication.
- Check the workspace for task-created leftovers as well as checking `git status`. Verify paths before deleting anything, and never delete unrelated user files or active browser profiles.
- Retain a preview only when the user explicitly asks for it as a deliverable.
